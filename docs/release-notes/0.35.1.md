**Submission checklist** gets its own ribbon button, an editable questions template and revisions for resubmissions.

- Submission checklist: the questions template can be edited on the owner's PC (add, edit, delete, Excel export and import) and travels in the model and in shared packs. There is one checklist per scheduled submission ("+ All"), and a resubmission after comments becomes a new revision (for example T3 Rev 1) that keeps the answers while approvals start again. The revetment type is removed, and combi-wall and relieving platform quay types are added.
- Ribbon: Submission checklist has its own button, and Test checklist moved to the pane. If a button looks out of place, restart Revit once.
- The TritoRevit tab sits after Sketch ProMax (else after SketchPro, else first).
- Submissions status: edit the schedule in Revit and the changes are written back to the setup Excel. Each submission has a start date, and you see hours worked in the model, hours expected left and hours needed per day.
