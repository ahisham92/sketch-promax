Move between chats while a chat or Autopilot is working: leaving a chat no longer stops its work. A model change asked in a second chat goes to the chat already working on that model.

- Each chat keeps its own answer, jobs and Autopilot running while you look at another chat; the Chats switcher shows which are working and which finished.
- Up to 3 chats can keep working in the background (each uses your plan while it works).
- One Autopilot per Revit window.
- Asking a second chat to change a model that another chat is already working on sends the request there, with a one-line note saying so; questions are still answered where you ask them.
