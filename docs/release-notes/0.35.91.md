Away mode's Esc ends only a command that is doing nothing, and away mode understands more ways of saying you're away.

- Away mode's Esc now ends only a command that is doing nothing (no processor, memory, file or journal activity for a full minute). It never ends a working command or a sync, open, save or link load (bug 104, please check).
- Away mode starts on any way of saying you're away: "I'll be away", "I won't be available", "going home", "in a meeting", "back in an hour", "carry on without me" and so on.
