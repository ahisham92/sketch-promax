Nine fixes from the bug log, faster bulk joins, export settings remembered per model, and crash-safe redo of chat changes.

**Fixes**
- Learned tools that open their own transactions now run without one around them (and with the 90 s cap).
- Chat attachments open in Excel or Word are read.
- Link tools read a linked model that is open in the same Revit.
- find_clashes: singular category names work; a centroid failure no longer stops the run.
- copy_dimensions: multi-segment spot dimensions no longer stop it.
- capture_view_image: zoom works in orthographic 3D views; other views are captured whole instead of refused.
- add_spot_elevations: refused spots are retried on the view's own faces.
- Exported chats head replies "Sketch ProMax".

**New**
- join_elements: bulk join or unjoin, one pair per step, never piles; one refused join no longer undoes the others.
- redo_steps: every chat change is kept with its full details, so a task lost in a crash can be replayed exactly.
- Export PDF and Export files remember this model's PDF/DWG setups, naming, units and coordinates.
- The chat saves rules you say with always/never, or give as corrections, without being asked; office practice and 6 one-click prompts added.
- Autopilot takes Sketch ProMax updates mid-run without losing work, and has its own limits in Settings > Chat > Autopilot.
