The chat shows its workers at their computers: they think and read the model at the same time, and changes to the model are applied one at a time.

- Each job's card says whether it is thinking, reading, waiting to apply or applying. The crew strip shows in the side pane too, one job per worker, and clicking a worker shows their jobs. Crew names can be changed in Settings > Chat.
- Several chat jobs at once no longer freeze Revit: a code step that runs more than 90 s stops by itself, changes nothing and is redone in smaller steps. Stop and the Rescue window now stop any code step (this came in 0.35.24).
- Auto sync: on a local copy of a central model, the chat syncs with central after every 250 changes (Settings > Chat), pausing jobs while it syncs.
