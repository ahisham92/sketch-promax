Licensed PCs can now get the owner's library: ready-made tools, recipes, kept code, done jobs and the checklist.

- The owner's PC uploads its library to GitHub locked, so only a PC with one of the owner's license keys can open it. A licensed PC fetches it when its key is activated and every half hour after that, and never overwrites its own tools or recipes.
- Keys made before this version don't open the library, so make a new key for each PC that should have it. The upload uses the GitHub token in License manager.
- The one-line installer now ends by showing the PC code to send for a key.
