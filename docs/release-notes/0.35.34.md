Chat crew upgrade: workers rotate and hand over to each other, the coordinator briefs each one and runs light so chats cost less, and a Team window shows how the team performs.

- Chats keep working in the background when you switch away; a Chats pill switches chats and shows which are working or finished.
- Each model keeps its own chat history (Save As takes it along).
- Clearer progress under each worker, a − N workers + control on the strip, thought bubbles showing what each worker is doing, and a list of what the applier is applying.
- Jobs-done badges, a leader star and a Team performance window (time, time saved, tokens and cost).
- Chat With coordinator costs less: the coordinator runs light on one model and keeps a short memory; jobs do the heavy work.
- A Simple chat is now a talk with one worker (its name shows on the type pill and answers). It suggests switching to With coordinator when a request is several tasks, the topics mix, or the chat gets heavy.
