**Lifeline:** Sketch ProMax now keeps a small file of each model's changes since its last save. After Revit closes by itself or a file is damaged, it puts those changes back, including floors, roofs, annotations and rebar.

- It works as soon as Sketch ProMax or TritoRevit is installed, with nothing to set up. Find it in the pane under Files > Lifeline, or in Settings > Recovery.
- It opens by itself when a model opens with unsaved changes left from a crash. It shows a preview first, then reports anything it couldn't put back.
- It brings back sketches (floors, ceilings, roofs, openings, railings, filled regions, lines), text, tags, dimensions, detail items, rooms and rebar.
- Lifeline can be shared with colleagues through Share tools.
