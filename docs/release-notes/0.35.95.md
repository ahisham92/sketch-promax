The Questions button is always there, and Lifeline can synchronize with central by itself if you turn it on.

- In 0.35.94 the Questions button could be missing. It is now always under the message box, and a question written in a reply (like "(a) ... or (b) ...") lands in the Questions tab with its choices (bug 109, please check).
- A second Lifeline option, off unless you turn it on, synchronizes with central every so many minutes (10 to 480, 60 by default). It waits while you are working, while a chat step runs, or while the server isn't answering. Set it in the Lifeline window or in Settings > Lifeline.
