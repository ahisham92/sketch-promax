Sync with Central no longer freezes while the chat works, and chat jobs finish faster.

- Revit could freeze for half an hour in Synchronize with Central while the chat was working: the chat's helper program held the central model's lock files it had inherited from Revit. Every program Sketch ProMax starts now inherits none of Revit's open files (bug 72).
- Jobs no longer save the model at the end of every run (each save held Revit for a minute or two while the other jobs waited). save_model now saves only when another open model links this one.
- A job that tries to load an edited family back inside a trial is told at once how to do it, instead of retrying for minutes.
- The activity log's answer times now show each answer's own thinking time, not the running total, so slow answers can be found.
- Bug reports keep the whole description; a freeze during Sketch ProMax's own work (an auto sync) is named as such; Lifeline no longer logs "The viewport is not on a sheet".
